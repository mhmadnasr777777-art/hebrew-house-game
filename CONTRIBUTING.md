# Contributing to Hebrew House Game | תרומה למשחק הבית בעברית

We love your input! We want to make contributing to this project as easy and transparent as possible.

## How to Contribute | איך לתרום

### 1. Fork the Repository
```bash
git clone https://github.com/your-username/hebrew-house-game.git
cd hebrew-house-game
```

### 2. Create a Feature Branch
```bash
git checkout -b feature/amazing-feature
```

### 3. Make Your Changes
- Follow the code style guidelines
- Add comments for complex logic
- Test your changes thoroughly

### 4. Commit Your Changes
```bash
git commit -m 'Add amazing feature'
```

### 5. Push to Your Fork
```bash
git push origin feature/amazing-feature
```

### 6. Open a Pull Request
- Describe your changes clearly
- Reference any related issues
- Include screenshots if applicable

## Code Style Guidelines | הנחיות סגנון הקוד

### JavaScript
- Use 2-space indentation
- Use meaningful variable names
- Add comments for complex logic
- Follow ES6+ conventions

### HTML
- Use semantic HTML elements
- Include proper lang attributes
- Maintain RTL support for Hebrew

### Documentation
- Keep README updated
- Document new features
- Add code comments
- Update DEVELOPMENT.md if needed

## Reporting Bugs | דיווח על באגים

Before creating a bug report, please:
1. Check the issue tracker
2. Test with latest version
3. Provide:
   - Browser and OS
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable

## Feature Requests | בקשות לתכונות חדשות

Feature requests are tracked as GitHub issues.
When creating a feature request, include:
- Clear description
- Use case/motivation
- Possible implementation
- Additional context

## Questions?

Feel free to open an issue or discussion for questions.
