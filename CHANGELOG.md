# Changelog | יומן השינויים

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-11

### Added
- Initial release of Hebrew House Game
- Full 3D house with multiple rooms (Living Room, Kitchen, Bedroom, Bathroom, Study, Hallway)
- WASD movement controls with smooth camera
- Interactive objects with Hebrew text-to-speech
- Dynamic lighting and shadows
- Web Speech API integration for Hebrew narration
- Web Audio API for sound effects
- Responsive design for desktop and mobile
- Complete documentation (README, Getting Started, Development Guide)
- MIT License
- GitHub Actions workflow for automatic deployment
- Contributing guidelines
- Code of Conduct

### Features
- 🏠 Fully explorable 3D house
