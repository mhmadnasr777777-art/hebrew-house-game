# Hebrew House Game | משחק הבית בעברית

A fully interactive 3D first-person house exploration game entirely in **Hebrew** (עברית). Built with **Three.js** for stunning 3D graphics and the **Web Speech API** for Hebrew text-to-speech narration.

## 🎮 Features | תכונות

- **🏠 Fully Explorable House**: Walk through a complete 3D house with multiple rooms
- **🎤 Hebrew Text-to-Speech**: All text is narrated in Hebrew using Web Speech API
- **🖱️ Interactive Objects**: Click on items to learn about them
- **⌨️ Smooth Controls**: WASD for movement, mouse for camera control
- **🌞 Dynamic Lighting**: Realistic lighting and shadows
- **📱 Responsive Design**: Works on desktop and mobile browsers
- **🎨 Beautiful Graphics**: High-quality 3D rendering with Three.js
- **🔊 Sound Effects**: Audio feedback for interactions
- **🌍 100% Web-Based**: No installation required, play in any browser

## 🚀 Quick Start | התחלה מהירה

## 🎮 How to Play | איך למשחק

### Controls | פקדים
| Key | Action | פעולה |
|-----|--------|--------|
| **W** | Move Forward | תנועה קדימה |
| **A** | Move Left | תנועה שמאלה |
| **S** | Move Backward | תנועה אחורה |
| **D** | Move Right | תנועה ימינה |
| **Mouse** | Look Around | להסתכל סביב |
| **Click** | Interact | אינטראקציה |

### Gameplay | משחק
1. **Explore** the house and look around
2. **Click** on objects to interact with them
3. **Listen** to Hebrew descriptions
4. **Discover** all rooms and their secrets
5. **Learn** about different areas of a Hebrew home
